I build machine-learning systems meant to run in production: leakage-safe training pipelines, transformer fine-tuning, RAG and agentic LLM systems, and the serving, testing and monitoring around them. I write the tests first, and I publish every number with how it was measured and where it stops holding.

## Work at a glance

**Agentic and LLM systems**
- [AAI SecureOps Assistant](https://github.com/SourabhaKK/vector-cartel): 2nd place hackathon. RAG assistant for industrial-control security; I built the agent and LLM layers.
- [ChronoScholar](https://github.com/SourabhaKK/ChronoScholar): research-memory agent that flags when new papers contradict stored claims.
- [Groundwork](https://github.com/SourabhaKK/Groundwork): UK company underwriting agent with citation-backed, confidence-rated reports.
- [LLM AI Basket Builder](https://github.com/SourabhaKK/llm-ai-basket-builder): LLM backend whose output passes deterministic dietary and budget rules.

**NLP and applied ML**
- [FinSight](https://github.com/SourabhaKK/FinSight): financial-news pipeline with a fine-tuned DistilBERT (0.9237 macro-F1), RAG over SEC and FOMC documents, drift monitoring.
- [Customer Churn Prediction](https://github.com/SourabhaKK/customer-churn-prediction-ml): leakage-safe scikit-learn pipeline, exported for serving.
- [Adaptive Fraud Detection](https://github.com/SourabhaKK/adaptive-fraud-detection-ml-pipeline): test-driven fraud pipeline on synthetic data, an engineering showcase.
- [NLP Complaint Classification](https://github.com/SourabhaKK/nlp-complaint-classification-pipeline): test-driven text classifier, TF-IDF or BERT.

**Serving and MLOps**
- [ML Model Deployment](https://github.com/SourabhaKK/ml-model-deployment-fastapi): hardened FastAPI inference service on AWS EC2 with auth, rate limiting and a circuit breaker.
- [ML Drift Detection](https://github.com/SourabhaKK/ml-model-monitoring-drift-detection): PSI, KS and Chi-Square drift engine with CI-friendly exit codes.
